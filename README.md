# Taskloom

**Taskloom** is a fast, keyboard-first desktop task and memo manager written in Rust.

## Features (Planned)
- **Fast & Lightweight:** Built natively in Rust with instant startup and low memory usage.
- **Keyboard-Driven:** Navigate, create, and organize tasks and memos without touching your mouse.
- **Local-First Storage:** Your tasks and notes stay on your machine in clean, human-readable files.

## Installation

### Build from Source
```bash
git clone https://github.com/umrao-ak47/taskloom.git
cd taskloom
cargo build --release
```
